Installation

  • Insert the DVD-ROM in your DVD-ROM drive.
  • If the installation does not start automatically, execute "autorun.exe" manually.
  • Select "Install" to install CANdelaStudio.
  • Follow the instructions to complete the software installation.

If you install the CANdelaStudio.msi directly in your specific software packaging process, ...

  • ensure all prerequisites contained in the CANdelaStudio installer are available on the system;
  • to avoid a reboot triggered by the CANdelaStudio.msi, pass REBOOTREQUIRED=0 to the msiexec call (as of 2017, the reboot is no more necessary and will be removed).

Font Setup

CANdelaStudio needs a Unicode font for proper operation:

  • The English and German user interface use the font "Arial Unicode MS".
  • The Japanese user interface uses a font better suited for Japanese characters.
  • The font of the RTF report is defined in the report template (installation folder, bin\Report\*.tmx).

In case your system does not have the font "Arial Unicode MS" (for the English/German user interface) or the font specified for the Japanese user interface, you can define a substitute for it in the Windows registry (command "regedit") as follows:

    key name     : HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\FontSubstitutes
    value name   : Arial Unicode MS
    example value: Arial

Historical note:

  • CANdelaStudio up to 8.0 installed a "font substitution".
  • CANdelaStudio since 8.1 no more uses this mechanism, since the "Arial Unicode MS" font is widely available.
